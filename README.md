Mirage (or Hueb-OS Mirage) belongs to the 'Hueb-OS' series of web operating systems, which are operating systems that attempt to replicate the functional architecture of a real operating system, adapted for the web browser.

Mirage is an experimental edition of the series, designed to explore entirely original and new features for a web operating system.

How do I access Mirage? [Click here](https://ucosuc113.github.io/Hueb-OS-mirage/)

What does the system include?:

The system contains the universal kernel of the Hue OS series.

The included apps are:

Constellation (Task Manager)
Terminal
Files
Chronicle
Settings
and Notes
